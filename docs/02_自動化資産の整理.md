## 4. 再挑戦の結果：謄本上げツールを完結させた

「このスクリプトを直して」ではなく「謄本上げ→DM発送までの業務を完結させる」視点で見直した結果：

```
① 候補地抽出        extract_parcels.py      ✅ 完成済み（PR #1）
② 所有者一括取得     外部サービス(ホームズ等)  💰 1筆140円〜
③ Excel統合→DMリスト merge_owners.py         ✅ 今回実装 ← 止まっていた箇所
```

`merge_owners.py` がやること：

- 一括取得サービスが返す所有者CSVを、①のExcelに自動照合・転記
  - サービスごとの**列名の揺れ**（氏名/名義人/所有者…）を吸収
  - **表記揺れ**（「高林１丁目」vs「高林一丁目」等の漢数字/全角半角）を正規化して照合
- **同一名義の複数筆を1行にまとめた「DMリスト」シート**を自動生成（筆数・合計坪数付き、坪数順）
- 法人・官公庁名義を自動判定して既定で除外（`--include-corp` で含められる）
- DM発送日・反応の記録列付き＝そのまま営業管理表になる

合成データでの検証済み（照合・転記・名義集約・法人除外すべて動作確認済み）。
残る人間の作業は「②のサービスにCSVを投入して結果を保存する」だけです。
