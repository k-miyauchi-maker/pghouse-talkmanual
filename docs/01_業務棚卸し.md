# 業務の棚卸し（2026年7月版）

宮内さんの実データ（Gmail直近3週間・カレンダー6/8〜7/11・Google Drive更新履歴・このリポジトリの依頼履歴）から
逆算した業務インベントリです。想像ではなく、**実際に流れていた通知・予定・ファイルだけ**を根拠にしています。

各業務を「入力 → 処理 → 出力」と「人間の判断が必要な箇所」に分解し、自動化の優先度を付けています。

---

## A. 毎日発生している業務（メール・通知ベース）

### A-1. 反響対応（PG HOUSE・FC各社・ウラ側ハウスLINE）

| 項目 | 内容 |
|---|---|
| 入力 | HP問い合わせ（no-reply@pg-house.jp）、イベント・見学会申込、資料請求、ALL GRIT（auka.jp）のLINE友だち追加・メッセージ通知、digimaリード通知。**1日数件〜十数件**が info@ 宛に着信 |
| 処理 | 通知メールを開く → リンク先で内容確認 → 担当者設定 → 対応方針決め → スプレッドシート等へ転記（あれば） |
| 出力 | 担当アサイン、1to1返信、名簿 |
| 人間の判断 | 「誰に振るか」「温度感の見極め」だけ。**開封・転記・集計は判断不要＝自動化対象** |

### A-2. セミナー・視察ツアー申込対応

| 項目 | 内容 |
|---|---|
| 入力 | 「セミナーの申し込みがありました【ピュアグロース】」メール（PGサマー、シリウス様視察＆講演ツアーin岩手 等）。申込者情報は毎回同じフォーマットの本文 |
| 処理 | 本文から氏名・企業名・役職・人数・きっかけを読み取り → 参加者リストへ転記 → 受付連絡 |
| 出力 | セミナー別参加者リスト、集客状況の把握 |
| 人間の判断 | ほぼ不要（重要顧客かどうかのフラグ付け程度）。**本文が定型なので機械抽出できる** |

### A-3. 採用対応

| 項目 | 内容 |
|---|---|
| 入力 | ビズリーチ応募・候補者メッセージ通知、HP採用エントリー（カジュアル面談希望）、doda等 |
| 処理 | 書類確認 → 合否選択 → 面接日程調整 → カレンダー登録（実際、カレンダーの単発予定の**約4割が面談・面接**） |
| 出力 | 選考ステータス、面接予定 |
| 人間の判断 | 合否判断・口説き。**候補者一覧化・日程調整・リマインドは自動化対象** |

### A-4. Chatworkのクライアント別チャンネル対応

| 項目 | 内容 |
|---|---|
| 入力 | 平松建築様、リバティホーム様（赤ペン先生）、プライムハウス様採用YouTube、ピースホーム様分譲、ファンライフ様、楓工務店さん×HOTLEAD…等、**クライアントごとの多数チャンネル**＋日報チャンネル |
| 処理 | 未読消化 → 都度回答。**同じ質問への説明を繰り返しがちな箇所**（サービス内容・進め方・過去に答えた内容） |
| 出力 | 回答、宿題 |
| 人間の判断 | コンサル判断そのもの。ただし**「よくある説明」はトークマニュアル/FAQ化して再利用可能**（このリポジトリの本来の目的） |

### A-5. 経理・契約の確認

| 項目 | 内容 |
|---|---|
| 入力 | freeeサイン署名完了通知、振込入金通知、請求書関連メール（例: 平松建築様への再送対応） |
| 処理 | 確認・締結・経理（keiri@）との連携。毎月25日「請求書発行」がカレンダーの定例 |
| 出力 | 締結済み契約、入金消込 |
| 人間の判断 | 金額・条件の確認のみ。ステータス管理は自動化余地あり（優先度は低め） |

## C. 繰り返し発生するコンテンツ制作（「何度も同じ形式で作っている」もの）

実はここが一番の資産で、**同じ型の成果物を手作業で量産している**状態です。

| 成果物 | 実例（Drive/note/メールより） | 型 |
|---|---|---|
| 住宅市場分析レポート | 「北海道・東北」「第4弾 関西」「第7弾 九州」…（digimaで無料配布→リード獲得） | 地方別に同じ構成 |
| note有料記事 | 「47都道府県No.1ビルダー完全解剖」（実際に売れている） | 都道府県×ビルダー分析 |
| 競合調査ダッシュボード | 一条工務店ダッシュボード（このリポジトリ）、シークレット一条勉強会、建売仕様比較、大手HM認定建築家ブランド比較、【アイ・ユニットG】競合調査票 | 会社別×都道府県別 |
| YouTube台本 | ウラ側ハウス_台本まとめ（ID263〜287） | 台本フォーマット |
| PGC合宿ワークシート | 京都社長合宿 経営者ワークシート、ロープレ＆FB | ワークシート型 |
| クライアント向けAI・業務自動化支援 | 【ホームライフ様】AI・業務自動化 要件定義シート | 要件定義→実装 |

→ **市場レポート・競合ダッシュボード・note記事は同じデータ基盤（住宅着工統計×企業データ）から派生**しており、
一条ダッシュボードの型を横展開すれば「1社調べたら1本作れる」パイプラインになります。
（このリポジトリの `.claude/skills/` に型をスキル化して収録済み。`docs/02_自動化資産の整理.md` 参照）

## D. 自動化の優先度マトリクス

| 優先度 | 業務 | 理由 | 次の一歩 |
|---|---|---|---|
| ★★★ | A-1/A-2 反響・申込の自動集計＋朝ダイジェスト | 件数が多く、判断不要の転記・集計が大半。マーケMTG・採用MTGの資料も兼ねられる | Gmail→スプレッドシート自動転記（Apps Script or Claude定期実行）。定型フォーマットなので抽出精度は高い |
| ★★★ | C 競合ダッシュボード・市場レポートの量産パイプライン | すでに一条版が完成しており、**型の再利用だけで済む**。noteの売上・digimaのリードに直結 | スキル `competitor-dashboard` を使って2社目を発注してみる |
| ★★☆ | 謄本上げ→DMリスト（touki-tool） | ツールは①抽出が完成済み、今回③統合も完成。あとは実データを流すだけ | G空間情報センターから浜松3区のGeoJSONを取得して実行（`touki-tool/README.md`） |
| ★★☆ | A-4 よくある説明のトークマニュアル/FAQ化 | このリポジトリの本来の目的。ウラ側ハウス台本・PGC資料という素材がDriveに揃っている | スキル `talkmanual` に手順を用意済み。素材を1つ渡して試作 |
| ★☆☆ | A-3 採用パイプラインの一覧化 | 効果は大きいがビズリーチ側の構造に依存 | まず通知メール→候補者トラッカー転記から |
| ★☆☆ | A-5 経理・契約 | freeeで概ね回っている | 現状維持で可 |

## E. 自動化しない（人間の判断として残す）もの

- クライアントへのコンサルティング判断・赤ペン指導の中身

- セミナー・視察のコンテンツそのものの企画
- 反響への1to1メッセージの最終文面（下書きまでは自動化可）
