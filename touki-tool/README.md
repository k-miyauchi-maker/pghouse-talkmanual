# 謄本上げ自動化ツール — 浜松150〜200坪リストの一斉Excel化

「謄本上げ→Excelリスト作成→土地活用提案」の前半工程を自動化するツール一式。

## 結論:できます

2023年1月から法務省が**登記所備付地図データ(公図の電子データ)を無償公開**しており、
浜松市の全筆の「所在・地番・区画ポリゴン」が無料で手に入ります。
区画ポリゴンから面積を計算すれば「150〜200坪の土地だけ」を機械的に全件抽出でき、
そのリストに対して登記情報(所有者)を一括取得すれば、従来1件ずつ手作業だった
謄本上げリストが**ほぼ全自動**で作れます。

## 全体フロー

```
① 候補地の全件抽出(無料)
   法務省 登記所備付地図データ(浜松市)
     → extract_parcels.py で 150〜200坪の筆を抽出
     → Excelリスト + 一括請求用CSV

② 所有者情報の一括取得(有料: 1筆140円〜)
   ①のCSVを一括取得サービスに投入
     → 所有者氏名・住所が返ってくる

③ Excelに統合 → DM・訪問営業リスト完成
```

## ① 候補地の全件抽出(このリポジトリのツール)

### データ入手

1. [G空間情報センター](https://front.geospatial.jp/moj-chizu-xml-readme/) に無料アカウント登録
2. 「法務省登記所備付地図データ」から**静岡県浜松市**のデータをダウンロード
   - 変換済みデータ(GeoJSON/シェープファイル)が提供されているのでそれを使うのが早い
   - 生の地図XMLしかない場合は [mojxml2geojson](https://github.com/digital-go-jp/mojxml2geojson)(デジタル庁製)や
     [mojxml-py](https://github.com/MIERUNE/mojxml-py)(高速版)でGeoJSONに変換
3. 浜松市は2024年の区再編後、**中央区・浜名区・天竜区**の3区。
   市区町村コード単位でファイルが分かれているので必要な区を全部落とす

### 実行

```bash
pip install openpyxl

python3 extract_parcels.py 浜松市中央区.geojson 浜松市浜名区.geojson \
    --min-tsubo 150 --max-tsubo 200 --buffer 0.1 \
    -o 浜松_150-200坪.xlsx --csv 一括請求用.csv
```

出力Excel: 所在 / 地番 / 図上面積㎡ / 図上坪数 / 精度区分 / 緯度経度 /
Googleマップリンク / 所有者記入欄(②で埋める)

### `--buffer 0.1` を推奨する理由

地図データに登記地積(公簿面積)は入っていないため、ポリゴンの**図上面積**で判定します。
公図の精度によって公簿面積と数%ズレるので、150〜200坪が欲しいなら±10%広げて
135〜220坪で拾い、謄本取得後に公簿地積で最終フィルタするのが確実です。

## ② 所有者情報の一括取得(サービス選択)

登記情報は公開情報なので誰でも取得できます。料金(2025年4月改定)は
**全部事項330円/筆、所有者事項140円/筆**。DMリスト用途なら所有者事項で十分。

| サービス | 特徴 | 向き |
|---|---|---|
| [登記情報提供サービス](https://www1.touki.or.jp/)(公式) | 1回10筆まで手動請求 | 少件数 |
| [ホームズ](https://www.homes-sys.co.jp/system/function/) | **CSV取込で一括取得(5分で1,200筆、1日15万筆)** | 本ツールのCSVと相性◎ |
| [登記簿図書館](https://xn--lcss68alvlysfomtekv.com/toki-service.html) | 1回500筆一括。会員間の二次利用データなら1筆280円→さらに安く | コスト重視 |
| [TRUSTART R.E.DATA](https://www.trustart.co.jp/products/redata/solution) | 地図上で範囲選択→一括取得、相続等の異動検知、DM発送代行まで | 営業まで外注したい場合 |

### コスト試算(目安)

浜松市で150〜200坪の宅地系候補が仮に3,000筆 → 所有者事項140円×3,000 = **42万円**。
用途地域(市街化区域・住居系)で先に絞れば数百筆〜に圧縮でき、数万円台で済みます。
浜松市の用途地域GISデータは[国土数値情報](https://nlftp.mlit.go.jp/ksj/)や浜松市オープンデータで無償公開されており、
①の抽出結果と重ねて絞り込み可能(応用編)。

## ③ Excel統合・さらなる自動化

- ②で返ってくるCSV/PDFを①のExcelにマージ(所在+地番でVLOOKUP)
- 登記情報PDFしか手に入らない場合は、Claude API等のAIで
  「所有者氏名・住所・地目・地積」を構造化抽出→Excel化が可能
- 発展形:
  - **建物ポリゴン(PLATEAU/基盤地図情報)と重ねて「建物のない150〜200坪」= 更地・駐車場だけ抽出**
  - 登記受付帳データで**相続・売買の異動があった土地だけ**を毎月自動検知(R.E.DATA等)
  - 地目「畑・田」を市街化区域内農地に絞って生産緑地・相続対策提案リスト化

## 法令・マナー上の注意

- 登記情報は公開情報であり、取得・リスト化自体は適法。ただし所有者の氏名住所は
  個人情報なので、**社内での安全管理措置・利用目的の範囲内での利用**が必要
  (個人情報保護法)。DMには送付元・問い合わせ先を明記すること
- G空間情報センターのデータは利用規約(出典明記等)に従うこと
- 図上面積は参考値。**提案書に載せる面積は必ず謄本の公簿地積か実測**を使うこと
