# トークマニュアル作成スキル

## 目的

Chatworkやセミナーで**何度も繰り返している説明**を、誰でも使える台本・FAQに固定化する。
対象読者: PG HOUSE FC加盟店の営業担当、ピュアグロース社内メンバー。

## 素材（Google Driveにある。Drive MCPで検索して読む）

- 「ウラ側ハウス_台本まとめ」（タブ版 ID263・267・270・274・275・276・287）— 顧客向けの語り口の宝庫
- PGC合宿ワークシート（「京都社長合宿」等）— 経営者向けの問いの立て方
- 「PGC2026社長面談ロープレ＆フィードバック」— 実際の面談での切り返し
- 「ワークシートB_冒頭5分の型と口説きスライド1枚」— 冒頭トークの型

## 構成（初版の目次案）

1. 冒頭5分の型（アイスブレイク→課題仮説→本題への橋）
2. 場面別トーク集
   - 初回反響への電話/LINE返信（ALL GRIT経由の反響を想定）
   - 資料請求者への追客
   - 見学会・相談会での説明
   - 価格・競合（大手HM、特に一条）への切り返し ← ダッシュボードの数字を武器にする
3. よくある質問と標準回答（FAQ）
4. NGトーク集（言ってはいけないこと・法令面の注意）

## 作法

- 1トピック=1ページ、話し言葉で書く（読む資料ではなく現場で使う台本）
- 競合数値は本リポジトリのダッシュボードから引き、出典と時点を添える
- 成果物は `talkmanual/` ディレクトリにMarkdownで置き、README.mdの地図に追加する
- 更新したら版数と日付を先頭に記録
