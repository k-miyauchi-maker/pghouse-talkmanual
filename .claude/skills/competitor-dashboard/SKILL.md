# 競合ダッシュボード量産スキル

## 型（マスター）

`ichijo_dashboard.html` がマスター。新しい会社のダッシュボードはこれを複製して作る。
**単一HTMLファイル完結**（データはJS内埋め込み、外部依存はChart.js/LeafletのCDNのみ）を必ず守る。

## 手順

1. `ichijo_dashboard.html` の構造を確認（KPI行7枚 / タブ: 都道府県テーブル・拠点ランキング・地図・体験館・グラフ分析）
2. 対象企業の公開情報を調査して同じデータ構造を作る:
   - 都道府県別: 年間棟数・拠点数・営業人数（推定可）・1拠点当たり棟数
   - 拠点一覧: 名称・住所・緯度経度（地図タブ用）
   - その会社固有の強み指標（一条ならPH=パラメータヒーター相当・HTC体験館。会社ごとに置き換える。例: 積水→シャーウッド展示場、タマ→長期優遇仕様）
3. ファイル名は `{会社ローマ字}_dashboard.html`（例: `sekisui_dashboard.html`）
4. ヘッダー色は会社コーポレートカラーに変える（CSSカスタムプロパティ `--primary` のみ変更）
5. README.md の「中身の地図」表に1行追加

## 出典の扱い

- データ出典と推定値の但し書きをダッシュボード末尾に必ず記載（noteの有料記事・勉強会資料に転用されるため）
- 更新時は既存データを消さず、`<!-- 2026-07更新 -->` のようにコメントで版を残す

## 派生物

このダッシュボードのデータは以下に再利用できる（頼まれたら提案する）:
- note有料記事（「47都道府県No.1ビルダー完全解剖」シリーズ）
- シークレット勉強会資料（Driveの「シークレット一条勉強会」参照）
- digima配布の市場レポート（→ `market-report` スキル）
