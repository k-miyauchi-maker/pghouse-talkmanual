# 謄本上げ→DMリスト作成スキル

## 全体フロー

```
① 候補地抽出(無料)     touki-tool/extract_parcels.py
② 所有者一括取得(有料)  外部サービス(人間が実施: ホームズ等、所有者事項140円/筆)
③ 統合→DMリスト        touki-tool/merge_owners.py
```

## 手順

1. **対象エリアと坪数レンジを確認**（既定: 浜松市3区・150〜200坪・buffer 0.1）
2. **①抽出**: ユーザーがG空間情報センターからGeoJSONをダウンロード済みか確認。
   未取得なら入手手順を案内（`touki-tool/README.md` の「データ入手」節）。
   ```bash
   python3 touki-tool/extract_parcels.py <区ごとの.geojson...> \
       --min-tsubo 150 --max-tsubo 200 --buffer 0.1 \
       -o <市名>_<レンジ>坪.xlsx --csv 一括請求用.csv
   ```
3. **②の案内**: 件数×140円のコスト目安を伝え、件数が多すぎる場合は用途地域での絞り込み（README応用編）を提案
4. **③統合**: 所有者CSVを受け取ったら
   ```bash
   python3 touki-tool/merge_owners.py <①のxlsx> <所有者.csv> -o <市名>_DMリスト.xlsx
   ```
   - 照合ヒット率が低い場合は、CSVの所在表記を確認（merge_owners.pyは丁目の漢数字・全角半角は自動吸収するが、大字省略などは手当てが必要）
5. 出力の「DMリスト」シート（名義集約済み・坪数順・法人除外済み）を成果物として案内

## 注意

- 図上面積は公簿面積とズレる。最終判定は謄本の公簿地積で行うことを毎回添える
- 個人情報（所有者名・住所）を含むファイルはリポジトリにコミットしない
